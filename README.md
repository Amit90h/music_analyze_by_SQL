# Music Store Data Analysis using SQL

## About

This project demonstrates SQL-based data analysis using a Music Store database. The goal is to explore customer purchasing behavior, sales performance, music preferences, and revenue trends by writing SQL queries ranging from basic to advanced levels.

The project covers real-world business questions using SQL concepts such as **JOINs, Aggregate Functions, GROUP BY, HAVING, Subqueries, Common Table Expressions (CTEs), Window Functions, Views, and Indexes**. These queries help extract meaningful insights that support business decision-making.

## Key Objectives

* Analyze customer purchasing behavior
* Identify top-selling artists, albums, and tracks
* Discover the most popular music genres
* Find the highest spending customers
* Calculate revenue by country and city
* Generate business insights using SQL

## Skills Demonstrated

* SQL Query Writing
* Data Analysis
* Database Joins
* Window Functions
* CTEs
* Aggregate Functions
* Query Optimization
* Business Intelligence

## Database

The project uses the **Chinook (Music Store)** sample database, which contains tables such as Customers, Invoices, Invoice_Items, Tracks, Albums, Artists, Genres, Employees, and Playlists.
